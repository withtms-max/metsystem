## Phase 0: 프로젝트 초기 셋업 (Day 1)

### 0-1. Next.js 프로젝트 생성
```bash
npx create-next-app@latest metsystem --typescript --tailwind --eslint --app --src-dir
```

### 0-2. 핵심 패키지 설치
```
shadcn/ui        → UI 컴포넌트 (버튼, 카드, 다이얼로그 등)
@supabase/ssr    → Supabase 서버/클라이언트 연동
@supabase/supabase-js → Supabase SDK
@dnd-kit/core    → 칸반보드 드래그앤드롭
lucide-react     → 아이콘
date-fns         → 날짜 처리
zustand          → 전역 상태관리 (가벼움)
next-pwa         → PWA 설정
```

### 0-3. Supabase 프로젝트 생성
```
1. supabase.com → New Project 생성
2. Project URL, anon key, service_role key 복사
3. .env.local 파일에 저장:
   NEXT_PUBLIC_SUPABASE_URL=xxx
   NEXT_PUBLIC_SUPABASE_ANON_KEY=xxx
   SUPABASE_SERVICE_ROLE_KEY=xxx
```

### 0-4. 폴더 구조 생성
```
src/
├── app/
│   ├── (auth)/login/page.tsx
│   ├── (salesperson)/layout.tsx      ← 하단탭 네비
│   ├── (manager)/layout.tsx          ← 관리자 레이아웃
│   └── api/
├── components/ui/
├── lib/supabase/
├── hooks/
└── types/
```

### 0-5. Supabase 클라이언트 설정
```
lib/supabase/client.ts   → 브라우저용 클라이언트
lib/supabase/server.ts   → 서버 컴포넌트용 클라이언트
lib/supabase/middleware.ts → 인증 미들웨어
```

**Phase 0 완료 체크:**
- [ ] `npm run dev`로 로컬 서버 정상 실행
- [ ] Supabase 대시보드 접속 가능
- [ ] shadcn/ui 컴포넌트 1개 렌더링 테스트

## Phase 3: 생명수 칸반보드 (Day 7-9)

### 3-1. DB 테이블 생성
```sql
pipeline_cards 테이블 + RLS
├── 월별 파티션 (month_key: '2026-05')
├── 스테이지: ta_target → ta_done → meeting_scheduled
│             → meeting_done → contract / on_hold
└── sort_order (드래그 순서 보존)
```

### 3-2. 칸반보드 메인 화면
```
(salesperson)/pipeline/page.tsx
├── 상단: 월 선택 [◀ 2026년 5월 ▶]
├── 요약 바: "TA대상 12명 | 미팅예정 5명 | 계약 2명"
├── 칸반 컬럼 (가로 스크롤)
│   ├── [TA 대상] ──────── 이번 달 전화할 사람들
│   │   ├── 고객 카드 (이름, 등급, 한줄메모)
│   │   ├── 고객 카드
│   │   └── [+ 추가]
│   ├── [TA 완료] ──────── 전화 완료
│   ├── [미팅 예정] ────── 약속 잡힘
│   ├── [미팅 완료] ────── 만남 완료
│   ├── [계약] ─────────── 성사!
│   └── [보류] ─────────── 다음 기회에
│
├── 드래그&드롭: 카드를 컬럼 간 이동
│   → 이동 시 activity_log에 자동 기록
│   → "TA대상 → TA완료" 이동 시 TA 1건 자동 카운트
│
└── 카드 탭 → 고객 상세 페이지 이동
```

### 3-3. 생명수에 고객 추가 플로우
```
[+ 추가] 버튼 탭
├── 바텀시트 올라옴
├── 내 고객 DB에서 검색 (이름/등급/지역)
├── 고객 선택 → 해당 월 칸반에 카드 생성
└── 이미 추가된 고객은 비활성 표시
```

### 3-4. 카드 상세 액션
```
카드 길게 누르기 (롱프레스)
├── [📞 전화 걸기] → 전화 앱 연동
├── [📝 메모 추가]
├── [스테이지 변경] → 셀렉트 드롭다운
└── [생명수에서 제거]
```

### 3-5. 칸반 → 활동 자동 기록 로직
```
스테이지 변경 이벤트 핸들러:

ta_target → ta_done:
  → activity_logs에 { type: 'ta_call', status: 'completed' } 자동 생성
  → 홈 화면 TA 카운트 +1

meeting_scheduled → meeting_done:
  → activity_logs에 { type: 'meeting', status: 'completed' } 자동 생성
  → 홈 화면 미팅 카운트 +1 (3칸 위젯 도장 찍힘)

any → contract:
  → activity_logs에 { type: 'contract', status: 'completed' } 자동 생성
  → 축하 애니메이션 🎉
```

**Phase 3 완료 체크:**
- [ ] 월별 칸반보드 렌더링
- [ ] 드래그&드롭으로 스테이지 이동
- [ ] 스테이지 이동 시 활동 자동 기록
